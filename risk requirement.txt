| Risk Level        | Description                                                                          | Examples                                                                                                                                                                                                                                        | Recommended Action                             |
| ----------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| **Informational** | General or personal prompts, no sensitive/internal info                              | “Write a story about a cat” / “What is my horoscope today?” / “Remind me to call mom”                                                                                                                                                           | Allow, log optionally                          |
| **Low**           | Safe text, no sensitive data                                                         | “Explain Kubernetes” / “Translate this sentence”                                                                                                                                                                                                | Allow, log optionally                          |
| **Medium**        | Some personal or internal info, low impact                                           | “Email John about project” / “Department workflow description”                                                                                                                                                                                  | Warn user, log event                           |
| **High**          | Specific personal/internal info, sensitive but not secret                            | “Employee list with emails” / “Internal project code names” / “Partial financial info”                                                                                                                                                          | Strong warning, allow override, log            |
| **Critical**      | Highly sensitive or secret data, including **pure confidential data with no filler** | - Passwords, API keys, tokens, database credentials<br>- NRIC / Passport numbers<br>- Full account numbers / pins<br>- Internal source code<br>- Pure confidential strings: `"John Doe 0192233445 12345-12-6789 Maybank Acc 1520xxxx Pin 5522"` | **Block send**, force warning, log as critical |
